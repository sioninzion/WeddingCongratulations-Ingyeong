# 결혼을 축하해요!

WeddingCongratulations의 채팅 목록, 말풍선, 노란 말씀 카드와 봉투 연출을 바탕으로
강인경 님을 위한 축하 메시지를 담았습니다. 제공된 픽셀 프로필을 이름별로 연결하고,
하단 메뉴는 카카오톡 형태의 아이콘으로 구성했습니다.

- 작성자 26명을 표시하며, `조성은 지휘자님`은 전체·🎶 채팅 목록의 맨 위에 표시합니다.
  나머지 멤버의 순서는 CSV 제출 순서를 유지하고, 별도로 받은 노시온 님의 편지를 끝에 추가했습니다.
- 제공된 26명의 픽셀 프로필을 채팅 목록, 대화방, 말씀 모아보기에 표시합니다.
  김태우 님이 포함된 최신 세트를 적용했습니다. 김세린·이예진의 손하트,
  김용빈·송성민·천지원의 브이, 우성원의 손가락 하트가 반영되어 있습니다.
  PNG 원본을 그대로 복사했으며, 이름으로 대조한 뒤 고유 ID 파일명으로 저장했습니다.
  이미지 URL에는 파일 해시를 붙여 새 이미지가 이전 캐시 대신 표시되도록 했습니다.
- 첫 축하말을 읽고 말씀을 받으면 추가 축하말이 나타납니다.
  말씀 카드는 단색 노란 제목 영역, 흰 본문, 회색 받기 버튼으로 간결하게 표현합니다.
- 대화방의 꺾쇠 아이콘과 `목록` 글씨가 있는 버튼을 누르면 채팅 목록으로 돌아갑니다.
  둥근 회색 배경과 테두리, 누를 때의 색상 변화로 버튼임을 표시합니다.
- 김예연 님의 추가 메시지는 사용자가 제공한 원본 사진으로 표시합니다.
- 추가 축하말이 없는 심지운·김현기 님은 말씀 확인까지 표시합니다.
- 원문의 문장, 이모지, 말씀 본문과 장·절 표기를 유지합니다.
- CSV 메시지의 날짜와 시간은 실제 작성 시각입니다. 작성 시각이 제공되지 않은 노시온 님의 편지는 날짜와 시간을 표시하지 않습니다.
- 읽음 상태는 현재 페이지를 연 동안 유지되며 새로고침하면 초기화됩니다.
- 각 대화방 하단에는 `함께 전한 마음, 오래도록 간직해요` 문구만 표시합니다.
  답장 입력·전송·저장 기능과 기존 답장 표시는 제거했습니다.
- 노시온 님의 편지는 `bas`에 배정했습니다. 말씀을 확인하면 마지막 축복 문장이 나타납니다.
- 새로고침 시 `뒤나미스의 마음을 모아,`와 `결혼을 축하해요!`를 먼저 표시합니다.
- 홈 광고를 누르면 `그건 바로 / 강인경` 팝업을 표시합니다.
- 하단 `대화`는 축하 메시지, `모아보기`는 작성자별 말씀 26개를 표시합니다.
  모아보기 아이콘은 두 말풍선 중 위쪽 말풍선에 십자가를 표시합니다.
- `소리`는 볼륨 막대만 열며, `친구`와 `더보기`는 화면을 전환하지 않습니다.
- 제공된 `돕는 배필.mp3`를 반복 재생합니다. 볼륨은 새로고침 시 50%입니다.
  브라우저의 자동재생 정책에 따라 첫 터치나 키 입력부터 음악이 재생될 수 있습니다.
- 채팅방 모아보기는 `전체`, `🎶`, `sop`, `alt`, `ten`, `bas`입니다.
  🎶 2명, sop 8명, alt 6명, ten 4명, bas 6명으로 26명 모두 배정했습니다.
  남시은은 alt, 박태민은 bas, 김용빈은 ten입니다.
- `조성은 지휘자님`과 `김예연`의 표시 이름은 목록·대화·말씀 팝업·말씀 모아보기에 공통 적용됩니다.

## 실행

이 폴더에서 다음 명령을 실행합니다. Python 3 외에 추가 패키지나 빌드 과정은 필요하지 않습니다.

```sh
./preview.command
```

브라우저에서 <http://127.0.0.1:4173>을 엽니다. 파일을 수정한 뒤 브라우저를 새로고침하면 반영됩니다.
종료하려면 실행 중인 터미널에서 `Ctrl+C`를 누릅니다.
다른 포트를 쓰려면 `./preview.command 4174`처럼 실행합니다.

## 수정 위치

| 파일 / 구간 | 내용 |
| --- | --- |
| `index.html` | 채팅 목록, 채팅방, 말씀 팝업의 HTML 구조 |
| `styles.css` | 색상, 글꼴, 화면 배치, 애니메이션 |
| `content.js`의 `siteContent` | 시작 문구, 대상 이름, 음악 경로, 기본 볼륨, 분류 목록 |
| `content.js`의 `members` 배열 | 26명의 메시지, 말씀, 사진 경로, 프로필 `avatarSrc`와 분류 `group` |
| `app.js` | 화면 전환, 분류, 말씀 모아보기, 읽음 표시, 음악 재생과 볼륨 |
| `assets/kim-yeyeon-message.png` | 김예연 님의 추가 메시지용 사진 |
| `assets/helping-partner.mp3` | 사용자가 제공한 배경음악 원본 |
| `assets/profiles/` | 이름별로 연결한 픽셀 프로필 PNG 26장 |

`content.js`에서 시작 문구와 내용을 수정할 수 있습니다.
멤버의 `group`에 `🎶`, `sop`, `alt`, `ten`, `bas` 중 하나를 지정하면 해당 분류에 표시됩니다.
`pinnedInChats: true`인 멤버는 해당 채팅 목록의 맨 위로 정렬됩니다.
프로필의 `avatarSrc`가 비어 있거나 이미지를 불러오지 못하면 기본 프로필을 표시합니다.
추가 메시지 사진은 편집하거나 자르지 않고 표시합니다.
